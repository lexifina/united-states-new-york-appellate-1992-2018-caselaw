# Roman v. 233 Broadway Owners, LLC

## Majority

The plaintiffs contention that the Supreme Court erred in granting the defendant ADT Security Services, Inc., leave to serve and file successive motions for summary judgment is improperly raised for the first time on this appeal and, therefore, is not properly before this Court.
There is no merit to the plaintiffs remaining contention that her note of issue should be reinstated. Angiolillo, J.R, Dickerson, Belen and Chambers, JJ., concur.
