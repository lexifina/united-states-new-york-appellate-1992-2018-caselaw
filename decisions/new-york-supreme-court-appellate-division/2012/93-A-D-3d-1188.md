# McCarthy v. CSX Transportation, Inc.

## Majority

Appeal and cross appeal from an order of the Supreme Court, Erie County (Frederick J. Marshall, J.), entered November 19, 2010. The order denied plaintiffs motion to set aside the verdict and denied defendant’s cross motion to set aside the verdict.
It is hereby ordered that the order so appealed from is unanimously affirmed without costs. Present — Scudder, PJ., Smith, Fahey, Garni and Sconiers, JJ.
